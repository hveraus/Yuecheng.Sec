# 越城院区智慧安保驾驶舱

基于 Three.js 的静态交互演示。执行 `npm run dev`，访问 http://localhost:5174。

- 三维院区概念模型，支持拖拽、缩放、自动环绕、线框模式与楼栋定位。
- 22 个演示设备点位，支持摄像头、门禁、消防、巡更图层独立切换。
- 告警定位、填写备注完成演示处置、巡更路径展示、调度表单、应急预案。
- 模拟摄像头视角均由三维场景生成，未接入真实摄像头或实时业务数据。
- 建筑布局、楼层、设备位置及全部统计均为演示数据，不代表院区实际情况。
- 不依赖第三方 CDN；Three.js 模块随站点提供。

接入实际项目时，用经授权的院区总平面/BIM模型替换概念模型，再关联设备坐标、视频平台与业务接口。
