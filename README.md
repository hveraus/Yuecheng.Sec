# 越城院区智慧安保驾驶舱

基于 Three.js 的交互演示。执行 `npm run dev`，访问 http://localhost:5174。

## 当前院区模型

模型以用户提供的东南角鸟瞰效果图与越城院区总平面图为参考，替换了初版通用建筑：

- 1号楼：弧形沿街主楼、双屋顶天井、绿色屋面与沿街雨棚。
- 2号楼：连续中央裙房、三个内庭院、院内联系廊。
- 3、5、6号楼：三栋平行条形楼体、圆角外轮廓、横向白色层带与玻璃窗带。
- 7、8、9号楼：独立组团，包含两栋条形楼体及弧形连接体。
- 10号楼：按总平面图位置设置的小型附属体。
- 跨河连廊、敬宾路、环路、景观水系、绿地、停车区域。
- 参考效果图增加外围林带、河岸树群和内庭院种植；树冠采用实例化多团簇建模，避开建筑、主路、停车区和连廊。种植位置为视觉示意。
- 河道与池塘使用连续流动的程序化水面，带水纹、反光和岸线；遵循系统减少动态效果设置。配合柔和方向光和建筑、树木投影。

总平面图未标出4号楼，模型不补造该编号。楼栋名称统一使用参考图编号，不推测临床科室或使用功能。

参考图保存在 `dist/assets/campus-render.png` 和 `dist/assets/campus-plan.png`，可通过页面“对照参考图”查看。

## 交互

- 效果图视角、平面图视角、正上方视角，支持旋转、缩放、自动环绕。
- “图纸配色”对应参考总平面图的楼栋色彩，“放大模型”扩展三维操作区。
- 9个编号楼栋和22个院区演示设备点位，独立摄像头、门禁、消防、巡更图层。
- 点击楼栋展开全部楼层；点击楼层或楼层编号隔离该层，支持俯视、返回展开与返回院区。
- 每层独立绑定2个摄像头、1个门禁、1个消防演示点位；点位跟随对应楼层，图层计数随当前楼层范围更新。楼层模型保留建筑外轮廓和庭院开口。
- 各层新增可开关的室内示意：有门洞的房间隔断、中央走廊、两处楼梯及一处电梯厅，采用独立颜色、房号与标识。全部为通用演示布局，不代表实际临床用途、交通核数量或疏散路线。
- 告警定位与处置、巡更路径、模拟监控视角、演示调度及应急预案。
- Three.js 本地模块，不依赖第三方CDN。

## 精度与数据范围

这是参考图片的外观及相对布局重建，不是经过测量的BIM模型。尺寸采用场景相对单位，层数和高度按视觉比例估算；未获得CAD、测量坐标或室内平面。三维模拟视角不是实时监控，全部设备点位与业务统计均为演示配置。

真实应用需以经核验的CAD/BIM模型与坐标校准，并接入视频和安保业务平台。

## 地下停车场

- 总容量700个：A–E区各100个普通车位，共500个；M区100组上下双层机械车位，共200个。机械上层不是另一地下楼层。
- 当前地下布局标记为B1剖切示意，提供坡道入口、柱网、车道和机械支架；未获得车库CAD，因此不代表现场柱网、通道或分区。
- 每个车位有唯一编号，M-001-L/U分别表示同一组下层/上层。上下层展开显示，支持单独筛选。
- 空位绿色，占用位橙色并展示车辆；支持模型拾取、编号列表定位、搜索、区域/状态/层位组合筛选。
- 初始演示占用386、空闲314；可切换选中车位的演示状态，模型、列表和计数同步。状态仅保留在本页会话，刷新重置；未接传感器或停车平台。

## 界面与动效

- 石墨玻璃主题、薄荷青主色与紫蓝辅助光；统一数据卡、模型工具栏、楼层、车库和弹窗样式。
- CSS立体数据装饰、悬浮轨道、安全指数环、图表入场与鼠标高光；装饰不移动实际操作区域。
- 顶部“动效开启 / 静态模式”控制装饰、水面与视角过渡，关闭时停止自动环绕。默认遵循系统减少动态效果设置，手动选择保存在当前浏览器。
